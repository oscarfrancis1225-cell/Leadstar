# Final Content QA Checklist

Complete this list before any article leaves draft.

## Reader value

- [ ] It genuinely answers the query.
- [ ] It contributes something the current top results do not.
- [ ] The opening earns the next paragraph.
- [ ] The opening question is resolved.
- [ ] The next step is useful, not pushy.

## Facts and compliance

- [ ] Facts are sourced in the fact ledger and marked VERIFIED.
- [ ] Numbers are current or omitted.
- [ ] No prohibited outcome language.
- [ ] Medicare bright line holds, if applicable.
- [ ] Disclaimers match the page type.
- [ ] Review attestation is signed; byline date matches `lastReviewedAt`.
- [ ] No invented clients, testimonials, credentials, or locations.

## Voice and SEO

- [ ] Sounds like a careful human writer.
- [ ] Keywords are natural.
- [ ] Title, H1, meta description, and canonical are unique.
- [ ] Answer-first summary is self-contained.
- [ ] Internal links use descriptive anchors (service, 3 related articles, tool if relevant, Esther/About/contact).

## Presentation

- [ ] Images are relevant; captions are truthful.
- [ ] Alt text describes the image.
- [ ] Heading hierarchy is valid.
- [ ] Tables are readable on a 390px viewport.
- [ ] Focus states and link purpose are clear.
- [ ] No information exists only inside an image.
